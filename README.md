# 🐍 Python Development Internship - Intermediate Level

This repository contains my solutions for the **Intermediate Level** tasks of the **Python Development Internship**. The projects focus on practical Python programming, web scraping, file handling, and game development while following clean coding practices and proper project structure.

---

## 📌 Internship Tasks

### ✅ Task 01 - Web Scraper

A Python-based web scraper that extracts information from the **ShadowFox** website using **Beautiful Soup**.

### Features

- Extracts website title
- Extracts the main heading
- Extracts website statistics
- Saves data in **CSV** format
- Saves data in **JSON** format
- Implements exception handling
- Uses modular project structure
- Includes logging support
- Organized output folder

### Technologies Used

- Python 3
- Requests
- BeautifulSoup4
- CSV
- JSON

### Folder Structure

```

│
├── output/
│   ├── shadowfox_data.csv
│   └── shadowfox_data.json
│
├── logs/
├── screenshots/
├── scraper.py
├── config.py
├── utils.py
└── README.md
```

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/Python-Development-Internship-Intermediate.git
```

Navigate into the project

```bash
cd Python-Development-Internship-Intermediate
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the virtual environment

### Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```
